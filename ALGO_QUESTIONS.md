# 1. Implement the "Promise.all" function

Implement the "Promise.all" function. The function should take an array of promises and return a promise that resolves to an array of the results of the promises. Or reject with the first error that occurs.
It should execute the promises in parallel.

# 2. Implement the Deepequal function

Implement the "DeepEqual" function. The function should take two arguments and return true if they are equal, false otherwise.
